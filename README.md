# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Учебный интернет-магазин «Перекупы 1С». Основа перенесена из проекта
контрольной работы №1 `kr1-html-css-shop`. Используются HTML, CSS и JavaScript
без Bootstrap, сборки и внешних зависимостей.

Рекомендуемое имя удалённого репозитория: `kr3-responsive-shop`.
Локальная папка проекта: `kr3`.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После запуска сервера откройте `http://localhost:8000`.

## Назначение файлов

- `index.html` — главная страница, товары, отзывы и модальное окно заявки.
- `catalog.html` — каталог с блоком фильтров.
- `product.html`, `product-2.html`, `product-3.html` — страницы трёх товаров с таблицами характеристик.
- `order.html` — отдельная страница заявки.
- `contacts.html` — контактная информация.
- `css/style.css` — исходные стили КР №1: оформление, переменные и компоненты.
- `css/responsive.css` — файл для адаптации по подходу Mobile First; подключён после `style.css` на всех семи страницах.
- `js/main.js` — мобильная навигация, модальное окно, выбор товара и клиентская проверка формы.
- `images/` — исходные фотографии, уменьшенные копии для карточек и три варианта hero-изображения.
- `lighthouse/` — итоговые отчёты Lighthouse и снимки интерфейса.

## Исправления доступности

| Найденная проблема | Исправление |
| --- | --- |
| Для перехода к содержимому требовалось пройти шапку | Первая ссылка по Tab ведёт к `main` и переводит туда фокус |
| Активный пункт меню обозначался только цветом | Добавлен `aria-current` для фактической текущей страницы |
| Не все элементы имели общий стиль фокуса | Общая обводка 3 px; для сегментов `input type="date"` используется `:focus-within` |
| После последнего поля диалога Chrome переводил фокус в панель браузера | Явный циклический обход Tab/Shift+Tab внутри диалога; Escape и закрытие возвращают фокус кнопке заказа |
| При сужении окна фокус мог оставаться в скрываемом меню | Фокус переносится к кнопке меню; при расширении с кнопки переносится в видимую навигацию |
| Переход по якорю скрывал меню с фокусом на его ссылке | Фокус передаётся целевому разделу |
| Выбранный товар хранился только в скрытом поле | Название товара показано в диалоге и связано с ним через `aria-describedby` |
| Формат телефона не был связан с полем | Подсказка получила `id`, поле — `aria-describedby` и `autocomplete="tel"` |
| Ошибки отображались только рамкой и подсказкой браузера | Добавлены постоянные тексты рядом с полями, связанные через `aria-describedby`, сводка `role="alert"` и фокус первой ошибки |
| Частично введённая необязательная дата блокировала отправку без пояснения рядом с полем | В обеих формах добавлено связанное сообщение для некорректной даты; очистка поля снимает ошибку |
| `aria-invalid` сохранялся после исправления значения | Ошибка и атрибут обновляются при вводе/изменении; очищаются при сбросе формы |
| Результат отправки только появлялся визуально | Сообщение имеет `role="status"`, получает фокус и сообщает об учебной имитации отправки |
| Без JavaScript `novalidate` отключал встроенную проверку | Теперь валидация браузера отключается только при подключении JS-обработчика |
| Светлые рамки полей сливались с фоном | Цвет границ изменён с `#e5dfd0` на `#8a806d` для полей формы и ценовых фильтров |
| Названия параметров таблицы были обычными ячейками | Использованы `th scope="row"` |
| Плавная прокрутка не учитывала системную настройку | Добавлен медиазапрос `prefers-reduced-motion` |

### Контрастность

Контраст рассчитан по относительной яркости sRGB для 17 пар цветов.
Основные результаты:

| Элемент | Пара цветов | Контраст |
| --- | --- | --- |
| Основной текст | `#26221a` / `#ffffff` | 15,84:1 |
| Второстепенный текст | `#6b6352` / `#ffffff` | 5,95:1 |
| Второстепенный текст на светлом фоне | `#6b6352` / `#faf7ee` | 5,55:1 |
| Ссылки | `#7a5200` / `#ffffff` | 6,92:1 |
| Текст основной кнопки | `#26221a` / `#ffd000` | 10,76:1 |
| Ошибки и текст бейджей | `#b00020` / `#ffffff` | 7,33:1 |
| Логотип | `#b00020` / `#ffd000` | 4,98:1 |
| Граница поля | `#8a806d` / `#ffffff` | 3,90:1 |

Все перечисленные текстовые пары превышают 4,5:1. Контраст границы поля
с белым фоном увеличен с 1,33:1 до 3,90:1 и превышает 3:1.
Пункты axe со статусом `incomplete` рассмотрены отдельно:

- звёзды отзывов состоят из символов, поэтому axe не классифицирует их как обычный текст; контраст `#b00020` на `#faf7ee` составляет 6,84:1, оценка также доступна через `aria-label`;
- часть ячеек таблиц на mobile обрезана прокручиваемым контейнером; реальные цвета текста и фона — `#26221a` и `#ffffff`, контраст 15,84:1, контейнер прокручивается клавиатурой;
- видимый знак «×» у закрытия является иконкой действия, скрыт через `aria-hidden`; кнопка имеет доступное имя «Закрыть окно заявки» через `aria-label`. axe оставляет сопоставление знака и имени для ручного рассмотрения.

Бейджи поверх фотографий имеют непрозрачный фон `#b00020`
и белый текст с контрастом 7,33:1.

### Проверки в браузере

Проверки сценариев выполнены через Playwright в headless Chrome.
axe не нашёл автоматических нарушений в 17 проверенных состояниях. Проверены:

- первая позиция Tab, появление skip-link и переход фокуса к `main` на семи страницах;
- обводка фокуса при обходе ссылок и полей;
- раскрытие мобильного меню клавишей Enter, переход Tab, Escape, якорь и смена ширины окна;
- открытие диалога Enter, обход в обе стороны, возврат фокуса при Escape и кнопке закрытия;
- пустые формы, короткое имя, ошибочный e-mail, неверный телефон, частично введённая дата и исправление полей;
- успешное заполнение и отправка обеих форм с клавиатуры, очистка и фокус сообщения результата;
- отсутствие общего горизонтального переполнения на семи страницах при ширинах 320, 360, 430, 768, 1024 и 1440 px;
- размеры диалога при 320 × 360, 360 × 640 и 768 × 600 px;
- горизонтальная прокрутка таблицы стрелками;
- отключение плавной прокрутки при уменьшении движения;
- доступность меню без JavaScript и отсутствие ошибок выполнения JS.
